# triage-mvp

Предварительный опрос пациента: семь вопросов текстом превращаются в
структурированную карточку для врача с категорией срочности.

**Живая ссылка:** https://triage-mvp-wet7.onrender.com/ (версия alpha, один сервис)

## Что делает

| ID | История | Где реализовано |
|---|---|---|
| US-1 | Диалог из 7 вопросов, состояние на сервере | `api/lib/store.js`, `web/app/survey` |
| US-2 | Структурированная карточка + черновик записи | `api/server.js` → `buildCard`, `web/components/Card.jsx` |
| US-3 | Тревожные признаки и 4 категории срочности, баннер 103 | `rules/triage.py`, `web/components/Card.jsx` |
| US-4 | Очередь по срочности, сводка, копирование записи | `web/app/doctor`, `rules/analytics.py` |
| US-0 | Работает без нашего ключа к API | `api/lib/llm.js`, `api/lib/fixtures.js` |

## Архитектура

```
браузер
   ↓  /api/*  (тот же origin, без CORS)
web — Next.js 16, серверный прокси-роут
   ↓  API_URL
api — Node + Express: диалог, карточка, очередь
   ↓  RULES_URL, таймаут 4 с, откат на JS-правила
rules — Python + FastAPI: срочность, длительность, сводка
```

Три независимых сервиса. Публичная ссылка — это `web`; остальные два ему служат.

## Запуск локально

Нужны три терминала.

```bash
# 1. правила
cd rules && pip install -r requirements.txt && uvicorn app:app --port 8000

# 2. API
cd api && npm install && RULES_URL=http://localhost:8000 PORT=3001 npm start

# 3. фронтенд
cd web && npm install && API_URL=http://localhost:3001 npm run dev
```

Открыть http://localhost:3000.

## Проверки

```bash
npm run smoke        # сквозной прогон 5 сценариев по всем трём сервисам
npm run test:rules   # 24 теста на правила (pytest)
npm run seed         # наполнить очередь врача демо-данными
npm run wake         # разбудить уснувшие инстансы перед показом
```

Все скрипты принимают `BASE_URL`, поэтому тот же прогон идёт по боевой ссылке:

```bash
BASE_URL=https://triage-web.onrender.com npm run smoke
```

## Деплой на Render

New → Blueprint → выбрать репозиторий. `render.yaml` поднимает все три сервиса и
сам прописывает `RULES_URL` и `API_URL` через `fromService` — руками адреса
вписывать не нужно. Публичная ссылка — сервис `triage-web`.

## Решения, которые стоит знать

**Вердикт считают правила, а не модель.** Категория срочности выводится
детерминированным кодом на Python. Иначе демо-режим и живой ключ давали бы
разные ответы, и проверяющий увидел бы не то, что мы показывали на репетиции.
Модель отвечает только за формулировку жалоб и черновик записи.

**Python-сервис не обязателен.** Node вызывает его с таймаутом в четыре
секунды. Если сервис спит или недоступен, карточка собирается по упрощённым
JS-правилам и честно помечается: разбор длительности стал грубее. Врач получает
карточку в любом случае — на бесплатном хостинге это не теоретический сценарий.

**Длительность разбирается, а не хранится строкой.** `rules/duration.py`
приводит «три недели», «минут сорок назад», «с 1 июля» и «11-го октября» к
числу дней. Когда пациент называет дату без года, система берёт прошлый год и
помечает карточку как требующую уточнения, а не делает вид, что поняла.

**Демо-режим включён по умолчанию.** `DEMO_MODE=1` проигрывает записанные
ответы модели из `api/lib/fixtures.js`. Публичная ссылка работает у постороннего
человека на чистой машине без нашего ключа — это условие допуска.

## Грабли, на которые уже наступили

- `\b` в JS не работает с кириллицей: `/недел/` ловит «поНЕДЕЛьник», `/год/` — «сеГОДня» и «поГОДа». В Python помогает lookbehind `(?<![а-яё])`, в JS — тот же приём.
- «минут сорок» — обычный порядок слов. Парсер, который ищет число только слева от единицы, превратит сорок минут в одну.
- `npm start` на Windows исполняет cmd, а не sh: `${PORT:-3000}` в скрипте не развернётся.
- Свободные инстансы Render засыпают через 15 минут; первый запрос после сна идёт ~30 секунд.
- Проверять публичную ссылку с телефона нужно по мобильному интернету, а не по домашнему Wi-Fi.

## Чего здесь нет

Голосового ввода, ролей и админки, интеграций с медицинскими информационными
системами, реальных персональных данных, авторизации сложнее пароля в
переменных окружения. Это MVP под критерии приёмки, а не продукт.
